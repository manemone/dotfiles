# dfxfer — ローカルマシンとのファイル受け渡し

このマシンは、人間の手元のマシン（ローカルマシン）と `dfup` / `dfdown`（どちらも
ローカルマシン側から叩くコマンド）を通じてファイルをやり取りしている。受け渡し場所は
このマシンのホーム直下:

| ディレクトリ | 向き | 意味 |
|---|---|---|
| `~/dfxfer/inbox/`  | ローカル → このマシン | 人間が `dfup` で送ってきたファイル。「inbox にこういうファイルが来てる」と言われたらここを見る |
| `~/dfxfer/outbox/` | このマシン → ローカル | 人間が `dfdown` で持ち帰る成果物を置く場所。「outbox に入れといて」と言われたらここに置く |

**転送は片道コピーで、消えない。** `dfup`/`dfdown` はどちらも `--delete` を使わないので、
`outbox` に置いたファイルは `dfdown` された後もこのマシン上に残り続ける。溜まってきても
勝手には消さず、消してよいか人間に確認すること。

このパスは既定値であり、ローカル側の `~/.zshrc.local`（`DFXFER_REMOTE_UP_DIR` /
`DFXFER_REMOTE_DOWN_DIR`）でマシンごとに変更されている可能性がある。`~/dfxfer/` が
存在しない、または `inbox`/`outbox` が見当たらない場合は、人間に受け渡し場所を確認すること
（別の設定になっている、またはこのマシンには `dfup`/`dfdown` がセットアップされていない
可能性がある）。
