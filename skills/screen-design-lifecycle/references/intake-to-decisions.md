# 工程 1・2: FB の取り込みから決めと記録まで

会議やレビューの FB を、画面で対応する決めにつなぐときに読む。読み手は司令官と、FB を整理する担当。

## 1. FB の取り込み

### 会議の要約に持たせる物

- 区分: **決定・検討・宿題** を分ける。決定とそれ以外が分かれていれば、後から根拠をたどれる
- 話者が分からない発言の扱い（部屋の発言を1人分として記録した、など）を、該当の節に書く
- 書き起こしの時刻（原本を引き直せる）
- 画面や Figma のコメントとの照合欄
- 出ていた人（役割）と、一次情報の所在。録音や記録が無い会議は、当日のメモの食い違いを1か所に整理する

### 読み違いを防ぐ

- 書き起こしは全文を読む。1回の要約を決定として確定しない
- ユーザーの確認が取れる前は、決定と書かず「仮置き」と書く
- **会議に出ていた人が「違う」と言ったら、要約の読みより本人の言葉を採る。** 食い違った点は、原本の書き起こしを別の会話に読み直させて直す
- 個人情報を書かない。発言は要約し、個人名を付けない

### FB の一覧

- 1件1行。番号（`FB-`）・画面・中身・区分・対応先の決め（`DEC-`）・状態
- 画面の章ごとに記号を付け、対応先の決めから逆引きできるようにする
- FB から「画面で対応が要る点」を整理して、決めの候補にする。候補ごとに、直す理由（どの FB か）を書く

## 2. 決めの文書

### 何のために1枚持つか

決まっていることを「何をどうする」と「なぜ」で1枚にまとめた文書。担当が代わっても、そこを読めば前提が揃う。

構成の例:

| 章 | 中身 |
|---|---|
| 1 作業の決まり | 進め方・守ること（例: 押した先が無いと決める前に、実装と別ページを見る） |
| 2 全画面に効く決定 | 画面をまたぐ決め |
| 3 画面ごとの決定 | 画面ごとの決め（`DEC-` の番号） |
| 4 設計の原則 | やらないこと |
| 5 未決 | 決まっていない物と、誰が決めるか |

### 育て方

- **決定が変わったら、決めの文書を先に直し、それから画面に反映する。** 順を逆にすると、担当が古い決めで動く
- 食い違ったら、日付が新しいほうが勝つ。その旨を文書の頭に書く
- 置き換わった決めは、本文を直さず印を付ける（「〜に置き換わった」と日付）
- 画面の外に漏れてはいけない前提（例: 画面の数字はすべて架空）も、1章に書く

## 3. 定義の文書

- 数字の分母・状態の言葉・外部の決まり（法令や規約など）を、1枚のチートシートにまとめる
- **画面の案を作る前に**作る。分母や言葉の食い違いは、画面を作った後の議論で初めて出て、作り直しの原因になる
- 画面の案を作る・直す前に、担当が読む文書として決めの文書から指す

## 4. 記録（見た目の決めを変える件）

- **1件1ファイル1PR。** Figma の変更はリポの差分に出ないので、記録をレビューの対象にする。書き方は `figma-design-workflow` の `references/record.md`
- 番号は司令官が連番で配る。傘をまたいで続ける（次の傘は、前の傘の最後の番号の次から）
- 枝番を作らない。欠番は、一覧に理由を1行書く
- 記録の一覧（`changes/README.md`）に、番号・題・対応する `DEC-`・日付を置く

## 5. 形が決まっていない物の進め方

形が決まっていない物（図の見せ方など）は、次の順にする。

1. **目的・見たいこと・出せるデータを先にそろえる。** 見た目の案から入ると、試作の不採用が続く
2. 試作置き場に新しいフレームで試作する。案は2つまで
3. ユーザーが見て決める
4. 画面に反映する。仮で入れた所は、記録に「仮」と書く

## 6. 判断を仰ぐ線引き

- ユーザーへ聞く: FB・記録・決めの文書で決められない物。見た目が目に見えて変わる物・意味が変わる物
- 司令官が決める: 数pxの余白、並びの細かい不揃い
- 司令官が決めたことも、決めの文書か記録に残す

## 出口

- FB の一覧の「画面で対応が要る点」が、すべて決めの文書の項目（または「対応しない」と理由）になっている
- 決めの文書と定義の文書を、ユーザーが確認した
- ここまで済んだら `figma-design-workflow` へ渡す

## よくある失敗

- 要約の読みを決定として確定し、会議に出ていた人の記憶と食い違う
- 決めの文書を後から作り、決まりが計画書の本文に散る
- 記録の番号を担当が取った順にして、枝番・欠番が理由なしに出る
- 目的を決める前に見た目の案を作り、試作の不採用が続く
