# Figma プラグイン（`figma@synced`）の有効範囲の検証

claude.ai から同期されたプラグイン `figma@synced` が、Claude Code の設定の階層（user / project / local）で
`enabledPlugins` により切り替えられるかを実測した結果と、その使い方を残す。
傘ブランチ `fixed-context` の孫7（Figma の有効範囲）の成果。

## 結論

効く。user で止めて、project の `.claude/settings.json` で戻せる。

| user（`~/.claude/settings.json`） | project（`.claude/settings.json`） | local（`.claude/settings.local.json`） | Figma のスキル | `figma@synced` |
|---|---|---|---|---|
| 未設定 | 未設定 | 未設定 | 14個 | 有効 |
| `false` | 未設定 | 未設定 | 0個 | 無効 |
| `false` | `true` | 未設定 | 14個 | 有効 |
| `false` | 未設定 | `true` | 14個 | 有効 |
| 未設定 | `false` | 未設定 | 0個 | 無効 |

つまり「ユーザー全体では止め、Figma を使うリポでだけ project 側で有効にする」運用ができる。
なお、同期プラグインは何も書かなければ有効になる（既定で有効）。

## 確かめ方

実際の `$HOME`（`~/.claude/settings.json`）は一切書き換えていない。

1. `mktemp -d` で一時ディレクトリを作り、その中に設定ディレクトリ（`cfg/`）と空の git リポジトリ（`proj/`）を用意する
2. `cfg/` に、実機の `~/.claude/.credentials.json`（認証）と `~/.claude/plugins/synced/`（同期プラグインの実体。約8MB）をコピーする。
   同期プラグインは認証と `plugins/synced/` が無いと読み込まれない（認証だけ持ち込んだ場合は Figma が現れず、比較にならなかった）
3. `CLAUDE_CONFIG_DIR=<cfg>` を付け、`proj/` の中でヘッドレス起動する:
   `claude -p hi --output-format stream-json --verbose --max-turns 1`
4. 最初に出る `system` / `init` イベントの `plugins`（`figma@synced` の有無）と `skills`（`figma:` で始まるものの数）を読む
5. `cfg/settings.json`（user 相当）と `proj/.claude/settings.json`・`proj/.claude/settings.local.json` を上の表のとおりに書き換えて、
   そのたびに 3〜4 を繰り返す
6. 終わったら一時ディレクトリを消す（認証ファイルのコピーが残らないようにする）

実測は Claude Code 2.1.300 で行った。

## machine 設定に書いた場合の生成結果

ユーザー全体で止める設定の置き場は `settings.machine.json`（このマシンだけ。傘の計画書 DOC-2610150519 の決定）。
`claude/deploy.sh` の `merge_claude_settings()` を取り出し、一時ファイルに対して次を確かめた。

- 配布物 `claude/settings.json` に `enabledPlugins` は無い。machine 設定に `{"enabledPlugins":{"figma@synced":false}}` を書くと、
  生成される設定にそのまま `"enabledPlugins": {"figma@synced": false}` として入る
- ベース側に `enabledPlugins` が既にある場合は、machine 側のキーが同じキーの深さで足される（浅い `update` のため、ベース側の
  別プラグインは消えない）。同じプラグインを両方で指定したら machine が勝つ

## 実機で止めるときの順序

リポ側（Figma を使う iosci・sheaf・pixidex）の `.claude/settings.json` に `"figma@synced": true` を入れて、
**それぞれの既定ブランチにマージされてから**、machine 設定で止めてデプロイする。先に止めると、
その間にそれらのリポで Figma が使えなくなる。手順は [claude/README.md](../../claude/README.md) §4.10。
